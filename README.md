 穿戴式裝置於智慧巡邏車之應用 (Application of a Wearable Device Control Platform for Smart Patrol Vehicles)

本專題旨在透過機電整合與邊緣運算技術，實現一台具備自主導航與人臉辨識功能之智慧巡邏機器人。系統採用「三層式硬體架構」：以筆記型電腦作為運算大腦，負責執行高負載之OpenCV人臉辨識；以Raspberry Pi 3B+作為通訊中樞，負責影像串流與指令轉發；並以ESP32微控制器作為底層控制小腦，結合MPU6050慣性測量單元與超音波感測器，在FreeRTOS即時作業系統上以雙核心多工方式，執行50Hz之PID姿態控制與自主避障。

本系統具備手套遙控與全自動巡邏之「雙模式狀態機」，並透過伺服馬達環景掃描搭配紅外線盲區偵測，實現不受固定路徑限制之動態閉迴路避障——系統於偵測到前方障礙時，先以伺服馬達進行0至180度環景測距，計算出最寬廣之開闊方向後，先行後退拉開安全距離，再轉向至計算所得角度，並具備卡角落自動脫困與輪組卡死救援機制；車身兩側另設有紅外線感測器，補強超音波之視野死角。測試結果展現出極高的系統穩定度與強悍的底層控制能力，具備未來投入智慧保全與居家監控之應用潛力。

系統架構

大腦 (PC 端): 負責高負載之 OpenCV/dlib 人臉辨識與最高決策。
腦幹 (Raspberry Pi 3B+): 負責影像 JPEG 壓縮串流與 UART/UDP 指令橋接。
小腦 (ESP32): 運行 FreeRTOS 雙核心多工，執行 50Hz PID 航向鎖定、超音波卡爾曼濾波與伺服馬達環景掃描避障。
手套遙控器 (ESP32 + MPU6050): 透過 ESP-NOW 無線協定實現低延遲體感控制。
